# Zeon

Mascota virtual con apariencia de dragón, basada en Tamaguino de Alojz Jakob.

Abre Zeon/Zeon.ino en Arduino IDE para la variante estándar, o el archivo .ino
de la carpeta correspondiente a tu placa y pantalla. Usa las bibliotecas y
configuración de la variante original. Compila y carga el código fuente.
Los archivos .hex originales se omiten porque contienen la versión anterior.
Esta adaptación no se ha compilado ni probado en una placa física.

Los documentos e imágenes de docs/ son los originales de referencia.
Se conservan los créditos y archivos de licencia originales.
Proyecto original: https://alojzjakob.github.io/Tamaguino/
